# Brif shabloni

Har bir video shu brifdan boshlanadi. Bo'sh qator qolmasin. Ma'lumot yetishmasa, foydalanuvchidan so'ra, o'zingdan to'qima.

```
[BREND / MAHSULOT] — [davomiylik] s video

Mahsulot: [bir qatorda: nima, kim uchun, qanday muammoni yechadi]
Auditoriya: [kim: yosh, kasb, B2B/B2C, shahar]
Maqsad: [lid yig'ish / brend tanitish / sotuv / taqdimot / B2B diler]
Joylashuv: [Instagram Reels / Stories / Meta reklama / Telegram / sayt / ko'rgazma ekrani]
Asosiy xabar: [tomoshabin eslab qolishi kerak bo'lgan BITTA jumla]

Ko'rsatilishi shart:
1. Hook: [og'riq yoki e'tiborni bir kadrda]
2. Muammo: [hozir mijoz nima qiladi va nega bu noqulay]
3. Yechim: [mahsulotning asosiy xususiyati]
4. Natija: [mahsulotdan keyingi holat, iloji bo'lsa raqam bilan]
5. Brend + CTA: [aniq harakat: "Ariza qoldiring", "Telegram'da yozing", narx/aksiya]

Ohang: [masalan: ishonchli, toza, tez; premium; do'stona]
Til: [o'zbek lotin / rus / ikkalasi]
Ovoz: [ovozsiz, faqat musiqa + SFX / diktor bor]

Formatlar: [asosiy: 9:16 1080×1920 yoki 16:9 1920×1080] + [qo'shimcha kesimlar]
FPS: 60 (yoki 30, agar reklama platformasi talab qilsa)

Aktivlar: [logo SVG, brend ranglari hex, shrift, mahsulot PNG (fonsiz), UI SVG, fon rasmlari]
Muddat: [sana]
```

## Tez savollar (mahsulot noma'lum bo'lsa)

1. Bu mahsulot kim uchun va qaysi muammoni yechadi?
2. Tomoshabin videodan keyin nima qilishi kerak?
3. Video qayerda ko'rsatiladi va qaysi format asosiy?
